Netlify is a cloud platform for building, deploying and scaling modern web applications, with continuous deployment from Git, serverless and edge functions, a global CDN, forms, identity, Postgres storage and an image CDN. Its public REST API at https://api.netlify.com/api/v1 is described by an OpenAPI that Netlify maintains in the open at github.com/netlify/open-api and serves at open-api.netlify.com, covering deploys, sites, DNS, builds, forms, environment variables and split tests. Netlify also ships an unusually complete agent surface: an RFC 9727 API catalog at the domain root, an OAuth-gated remote MCP server, fifteen published Agent Skills, an llms.txt, and a Markdown twin of every documentation page.

**Areas:** CDN · Cloud · Continuous Deployment · Developer Tools · Edge Computing · JAMstack · Serverless · Serverless Functions · Static Sites · Web Hosting · Websites · Netlify

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Netlify: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
