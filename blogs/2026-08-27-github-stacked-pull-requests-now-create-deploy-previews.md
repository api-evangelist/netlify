Netlify now creates a Deploy Preview for every pull request in a GitHub stack when the stack ultimately targets your project’s production branch (usually main). You can review and share each layer of a larger change before it merges. A GitHub stacked pull request showing a successful Netlify Deploy Preview check GitHub Stacked Pull Requests help teams split a larger update into smaller, connected pull requests.
