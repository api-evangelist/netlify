Agent Runners can now scope ambitious prompts for new projects to create a partial working project and provide next steps within the available credit budget. Previously, a brand new project could use up its credit budget before the agent finished for ambitious prompts, leaving the run marked Cancelled partway through. Now, your agent scopes the work more intelligently.
